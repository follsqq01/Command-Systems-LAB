# Мобильная версия

- До 600 px: вложенные орбиты по референсу. Композиция пропорционально масштабируется, включая подписи — это выбранный пользователем вариант.
- От 601 px: исходный блок с перетаскиваемыми плашками (`src/sections/DesktopFormatMap.tsx`).
- До 900 px: мобильные отступы и типографика, обычная прокрутка форматов, горизонтальная прокрутка карточек спикеров.

## Что редактировать

`src/sections/FormatMap.tsx`: массив `labels` — подписи, цвета, кольцо, начальный угол и ширина. Массив `dots` — кружочки. Ширины заданы относительно базовой композиции 355 px и масштабируются через cqw. Всё остаётся HTML-текстом, фон и контуры — CSS.

`src/styles.css`: блок `Phone-only reference composition`, переменная `--orbit-period` (100 секунд на оборот). Все элементы используют один период; обратное вращение сохраняет горизонтальное положение текста. Системный режим уменьшенного движения выключает вращение.

`src/sections/Program.tsx`: время, название, участники, цвет точки. Высота строк зависит от текста; новые переносы не сдвигают временную шкалу.

## Проверка после изменения подписей

Проверить в браузере размеры 320 / 375 / 390 / 430 / 600 px. Увеличение длины текста или размера шрифта требует повторной проверки расстояний между плашками. `design/check-orbit.mjs` проверяет полный оборот с шагом 0,1° по сохранённым измерениям браузера из `design/qa/mobile-refresh/orbit-checks.json`; после правок текста/типографики эти измерения нужно обновить. Тест не снимает новые измерения автоматически.

Команды: `npm run build`, `node design/check-orbit.mjs`.
