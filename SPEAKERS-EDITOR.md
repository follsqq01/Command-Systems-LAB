# Редактор спикеров

В обычном просмотре `npm run dev` и на опубликованном сайте кнопок редактирования нет. Чтобы внести новые правки, остановите обычный локальный сервер и запустите `npm run edit:speakers`. Откройте `http://127.0.0.1:4174/#speakers` и нажмите «Редактировать спикеров». После сохранения остановите редактор и снова запустите `npm run dev`.

- «+ Добавить спикера» создаёт новую карточку. Впишите имя и описание прямо в неё.
- «Добавить фото» или «Заменить фото» принимает PNG, JPEG и WebP до 8 МБ. Фотография записывается в `public/uploads/speakers/`.
- Ползунки сдвигают изображение внутри круглой рамки и меняют масштаб. Список «Режим фото» задаёт заполнение круга или показ всего изображения. Результат виден сразу.
- Стрелки переставляют карточки. Первое фото располагается снизу, второе сверху, далее порядок автоматически чередуется. При перестановке или удалении тип карточки пересчитывается.
- «Удалить» убирает карточку из черновика. «Отмена» возвращает уже сохранённый список. «Сохранить изменения» записывает карточки в `public/content/speakers.json` и они остаются после перезагрузки страницы.

Редактор работает только на **локальном сервере разработки**, когда он запущен командой `npm run edit:speakers`. Этот режим привязан к `127.0.0.1` и не является входом по паролю. Сборка `npm run build` включает сохранённые данные и фотографии в `dist/`, но не включает редактор. После публикации статической сборки изменения на локальном сайте нужно снова собрать и опубликовать. Для редактирования уже опубликованного сайта с любого устройства потребуется серверное хранилище и вход администратора.
